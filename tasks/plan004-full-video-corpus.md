# plan004-full-video-corpus

## 목적

월가아재 공식 채널의 전체 공개 영상을 멀티모달로 훑는 코퍼스 수집 파이프라인을 완성한다.
이 plan 은 나중에 병렬 실행자가 중단과 재개를 반복해도 같은 근거 구조를 남기게 만든다.

## 의존 관계

- `plan003-wsaj-wiki-mvp`

이 plan 은 `plan003` 이 정의하는 근거 스키마와 답변 계약을 전제한다.
`plan003` 이 아직 병합되지 않았으면 최신 base 를 확인하고 멈춘다.

## 소유 파일

- `docs/wsaj-corpus.md`
- `scripts/wsaj_video_corpus.py`
- `tests/test_wsaj_video_corpus.py`
- `.gitignore`

## 범위

- 공식 채널의 공개 영상 목록을 수집한다.
- 영상 파일, 음성 전사, 화면 프레임 근거를 연결한다.
- 영상별 처리 상태, 실패 사유, 재시도 가능 여부를 남긴다.
- 원본 영상, 쿠키, 대형 중간 산출물이 Git 에 들어가지 않게 확인한다.
- 테스트가 처리 상태와 재개 동작을 검증하게 한다.

## 범위 밖

- 비공개 영상, 멤버십 영상, 개인 메시지 수집.
- 월가아재 본인처럼 답하는 인물 모사 구현.
- 최신 종목 추천 엔진.

## 완료 기준

- 영상 목록의 출처와 수집 시점이 남는다.
- 영상별로 음성 근거와 화면 근거가 연결된다.
- 실패한 영상은 실패 사유와 재시도 기준을 가진다.
- 중단 후 재실행해도 이미 처리한 영상을 불필요하게 다시 처리하지 않는다.
- `reports/`, `.cache/`, 쿠키 파일, 영상 원본은 Git 에 추적되지 않는다.

## 검증 명령

```bash
python3 scripts/wsaj_video_corpus.py --help
python3 -m unittest -v tests/test_wsaj_video_corpus.py
git status --ignored --short reports .cache
```

전체 코퍼스 수집은 시간이 오래 걸릴 수 있다.
PR 검증에서는 작은 샘플로 동작을 확인하고, 전체 실행은 별도 운영 기록으로 남긴다.

## 원자 커밋 기준

이 plan 은 전체 영상 코퍼스 수집 파이프라인만 하나의 커밋과 PR로 묶는다.
brain 답변 품질 개선이나 가치평가 코드 변경이 섞이면 중단한다.
