# ADR: 월가아재 자료 기반 챗봇을 근거형 연구 보조 도구로 둔다

## 상태

채택.

## 배경

사용자는 월가아재 영상에서 투자 가치관과 가치평가 프로세스를 추출해, 주식 질문을 주고받을 수 있는 개인용 brain 을 만들고 싶어한다.
이 목표는 유용하지만, 인물의 말투와 판단을 흉내 내는 챗봇으로 만들면 근거 없는 답변과 오인 가능성이 커진다.

투자 질문에는 현재 주가, 실적, 컨센서스, 금리, 뉴스처럼 시간이 지나면 바뀌는 값도 섞인다.
영상 근거만으로 현재 종목 질문에 답하면 오래된 사실을 현재 사실처럼 말할 위험이 있다.

## 결정

인물 대역 챗봇은 만들지 않는다.
대신 월가아재 영상과 문서에서 확인한 원칙을 근거로 삼는 투자 연구 보조 도구를 만든다.

## 저장 범위 확장

이 ADR의 인물 모사 금지와 근거형 답변 결정은 유지한다.
다만 저장 위치와 확장 범위는 [ADR-0003](0003-tool-independent-multi-expert-wiki.md) 이 확장한다.
월가아재 전용 자료는 `expert_id=wsaj` 로 새 `wiki/experts/` 구조 안에 들어간다.

답변은 다음 세 가지를 분리한다.

| 구분 | 처리 |
| --- | --- |
| 직접 근거 | 영상 제목, URL, 타임스탬프, 증거 ID 를 붙인다 |
| 추론한 원칙 | 추론이라고 밝히고 여러 직접 근거를 묶는다 |
| 현재 시장 사실 | 현재 데이터 연결 경계로 새로 조회하고 조회일을 붙인다 |

핵심 주장이 `unsupported` 이거나 시점이 불명확하면 답하지 않는다.
답하지 않는 경우에는 부족한 근거와 필요한 추가 조회를 말한다.

## 대안

| 대안 | 판단 |
| --- | --- |
| 월가아재 말투와 판단을 흉내 내는 인물 모사 챗봇 | 기각. 사용자가 실제 인물 답변으로 오해할 수 있고, 근거 없는 투자 조언으로 흐르기 쉽다 |
| 영상 전사문 전체를 검색해 답하는 RAG | 기각. 긴 원문을 그대로 저장하고 검색하면 저작권과 잡음 문제가 커지고, 근거 품질을 통제하기 어렵다 |
| 사람이 검토한 증거 단위와 wiki 를 따로 두는 방식 | 채택. 느리지만 근거 품질과 거절 조건을 관리할 수 있다 |

## 결과

시스템은 “월가아재가 이렇게 말한다”가 아니라 “월가아재 자료에서 확인되는 원칙은 이렇다”라고 답한다.
사용자는 영상 근거가 있는 주장과 현재 데이터로 갱신한 사실을 구분해서 볼 수 있다.

이 결정은 인물과 말투의 재현을 포기한다.
대신 근거가 있는 투자 연구 하네스를 얻는다.

## 검증 조건

답변 스킬은 다음 조건을 통과해야 한다.

1. 모든 핵심 주장에 `claim_type` 이 붙는다.
2. `direct_claim` 과 `inferred_principle` 에는 증거 ID 가 붙는다.
3. `current_external_data` 에는 조회일과 제공자가 붙는다.
4. `unsupported` 는 결론 문장으로 쓰이지 않는다.
5. 종목 질문에서 현재 가격이나 실적이 필요하면 현재 데이터 연결 경계를 통과한다.
6. 50문항 평가에서 인용 유효성 90% 이상, 근거 부족 거절률 95% 이상을 만족한다.
7. 같은 평가에서 숫자와 시점 오류가 한 건도 없어야 한다.
