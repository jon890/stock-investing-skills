# ADR: 투자 공통 용어와 expert 용어를 분리한다

## 상태

채택.

## 배경

기존 `docs/glossary.md` 는 일반 금융 용어와 월가아재가 강조한 표현을 한 표에 담았다.
이 구조에서는 일반 투자 스킬이 월가아재 자료를 공통 정의처럼 읽거나, 다른 expert 를 추가할 때 한 인물의 해석이 전체 Wiki의 표준처럼 보일 수 있다.

[ADR-0003](0003-tool-independent-multi-expert-wiki.md) 은 expert 별 provenance 를 분리하기로 결정했다.
용어도 같은 원칙을 따라 일반 정의와 인물별 용례를 분리해야 한다.

## 결정

`docs/glossary.md` 는 특정 expert 와 무관한 투자 공통 용어집으로 둔다.
일반 정의, 계산 방식, 적용 범위, 오용 주의를 설명한다.

각 expert 의 용어 사용은 `wiki/experts/<expert_id>/glossary.md` 에 둔다.
이 문서는 해당 인물이 자주 쓰거나 별도로 강조한 의미, 적용 맥락, 오용 위험, 증거 ID를 설명한다.

같은 용어가 두 문서에 함께 있을 수 있다.
공통 용어집은 일반 정의를 소유하고, expert 용어집은 인물별 해석과 출처를 소유한다.
한쪽 내용을 다른 쪽의 근거로 대신하지 않는다.

## 대안

| 대안 | 판단 |
| --- | --- |
| 하나의 전역 용어집에 모든 expert 용례를 추가 | 기각. 출처가 늘수록 일반 정의와 인물별 해석이 섞인다 |
| expert 용어집만 유지 | 기각. 일반 투자 스킬이 특정 인물 자료에 의존하게 된다 |
| 공통 용어집과 expert 별 용어집을 분리 | 채택. 일반 상식과 provenance 를 함께 보존한다 |

## 결과

`tenbagger-pick` 같은 일반 스킬은 `docs/glossary.md` 를 읽는다.
`investing-wiki` 는 일반 뜻이 필요할 때 공통 용어집을 읽고, 특정 expert 의 용례를 답할 때 해당 expert 용어집과 증거를 함께 읽는다.

새 expert 에게 고유한 용어가 없으면 `glossary.md` 는 선택 사항이다.
용어집을 만들면 profile 의 `paths.glossary` 에 상대 경로를 기록한다.

## 검증 조건

1. 공통 용어집에는 특정 expert 의 영상 ID나 인물별 주장만을 근거로 한 정의가 없다.
2. expert 용어집의 인물별 설명은 증거 ID나 원자료 위치를 가진다.
3. 일반 스킬은 expert 용어집을 공통 정의의 원본으로 사용하지 않는다.
4. expert 전용 스킬은 공통 정의와 인물별 해석을 구분해서 읽는다.
