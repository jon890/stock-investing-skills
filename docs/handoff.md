# 인계 기록

이 문서는 세션이 바뀌어도 작업을 이어갈 수 있게 지금까지의 결정과 남은 일을 담는다.
목표와 원칙은 `docs/prd.md`, 데이터 함정은 `CLAUDE.md`, 실행 절차는
`skills/daily-market-decision/SKILL.md` 가 소유한다. 이 문서는 그 셋을 반복하지 않는다.

## 지금 상태

파이프라인 세 단계가 모두 돌아가고 산출물이 나온다.

| 단계 | 스크립트 | 상태 |
| --- | --- | --- |
| 유니버스 수집 | `scripts/fetch_universe.sh` | 미국 491개, 한국 493개 수집 확인 |
| 병목 점수 | `scripts/bottleneck.py` | 미국 25개 산업 그룹 점수 산출 확인 |
| 밸류에이션 | `scripts/valuation.py` | CRDO 와 MRVL 로 검증 |
| 리포트 | `scripts/render_report.py` | HTML 두 종류 생성 확인 |

스킬은 `~/.claude/skills/daily-market-decision` 에 심링크로 걸려 있어 어느 세션에서든 호출된다.

## 사용자가 정한 것

시간 순서대로 쌓인 결정이다. 나중 것이 앞의 것을 덮는다.

| 결정 | 내용 |
| --- | --- |
| 목표 | 2년 안에 10배가 될 종목 발굴. 처음에는 10년이었다가 2년으로 좁혔다 |
| 접근 | 탑다운. 병목 섹터를 먼저 정량 선별하고 그 안에서 종목을 고른다 |
| 팩터 | 병목 팩터와 가중치는 내가 정한다. 사용자가 위임했다 |
| 종목 선정 | 전부 자동 |
| 밸류에이션 | 절대가치와 상대가치를 **따로** 낸다. 가중평균은 쓰지 않는다 |
| DCF | 명시 예측 5년, 영구성장률은 보수적으로 |
| 산출물 | 로컬 HTML 파일. 외부에 게시하지 않는다 |
| 범위 | 미국과 한국. 한국은 데이터 한계로 보류 상태다 |
| 저장소 | 이 폴더 하나에서 작업한다 |

## 남은 일

우선순위 순이다.

### 1. 병목 점수를 2년 텐베거 목표에 맞춘다

지금 다섯 팩터의 가중치는 10년 목표로 잡은 값이다.
`미반영 여지` 가 10% 인데, 2년 안에 배수가 2.5배 확대될 여지를 찾으려면 이 축이 훨씬 무거워야 한다.
`수요 초과` 도 성장률의 절대 크기가 아니라 **가속도**를 봐야 한다.

`scripts/bottleneck.py` 의 `FACTORS` 를 고친다.

### 2. 후보 선별에 진폭을 넣는다

`tenbagger_candidates` 는 시총 상한과 성장 하한만 본다.
5년 매출 추정의 진폭이 큰 기업을 골라야 하는데 그 축이 없다.
진폭은 `valuation.py` 의 `tenbagger()` 가 `spread` 로 내지만, 후보 선별 단계에서는
가정 파일이 없어 계산할 수 없다. 가정 없이 진폭을 근사하는 방법이 필요하다.

### 3. 남은 후보를 돌린다

5710 그룹의 텐베거 후보 6개 중 CRDO 만 봤다.
GFS(254억), SMCI(249억), TSEM(248억), MCHP(410억) 가 남았다.
각각 `scripts/inputs/<티커>.json` 을 만들면 된다. 계산 코드는 고치지 않는다.

### 4. 한국 시장

컨센서스 추정 보유율이 26% 이고 시가총액이 원화다.
환율 변환과 결측 처리를 넣기 전까지 한국 종목 선별은 하지 않는다.

### 5. 유니버스의 크기

valley 히트맵은 시장당 약 490개만 준다. 대형주에 치우쳐 있다.
2년 텐베거 후보는 시총 100억 달러 이하에서 나오는데 그 구간이 얇다.
valley 의 퀀트 스크리너(`/screener/basic/screening`)가 더 넓은 유니버스를 줄 수 있다. 확인하지 않았다.

| CRDO | $112.02 (-53%) 비중 축소 | $269.49 (+12%) 비중 확대 | 미달. 최선 1.0배, 진폭 7.7배 |

AI 반도체 섹터 전체가 현금흐름으로 정당화되지 않는 값에 있다는 뜻이다.

## 되돌아본 실수

같은 실수를 반복하지 않으려고 남긴다. 상세는 `CLAUDE.md` 의 함정 절에 있다.

- 텐베거 목표가 나오기 전에 고른 종목(MRVL)을 그대로 밀고 갔다.
  목표가 바뀌면 후보부터 다시 고른다.
- 배수 불변을 가정한 텐베거 판정이 목표주가와 정반대 결론을 냈다.
- TAM 을 2028년 값으로 넣고 2036년 매출과 비교했다.
- 비교군 배수를 한 해만 교체해 성장률이 140% 로 잡혔다.
- 이분법의 증감 방향을 가정해 구간 끝값이 답으로 나왔다.
