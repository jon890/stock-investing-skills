# 인계 기록

이 문서는 세션이 바뀌어도 작업을 이어갈 수 있게 현재 결정과 남은 일을 압축해 둔다.
이 저장소의 기준 문서는 `docs/prd.md`, `docs/flow.md`, `docs/glossary.md`, `docs/code-architecture.md` 다.

## 현재 구조

- 섹터 병목 진입점은 `skills/sector-bottleneck/SKILL.md` 다.
- 종목 선별과 가치평가는 `skills/tenbagger-pick/SKILL.md` 가 담당한다.
- 월가아재 공개 영상 기반의 철학/용어 조회는 `skills/wsaj-investing-brain/SKILL.md` 가 담당한다.
- `skills/daily-market-decision/SKILL.md` 는 삭제했다. 옛 이름은 더 이상 새 작업의 진입점으로 쓰지 않는다.

## 월가아재 브레인

`wsaj-investing-brain` 은 월가아재 공개 영상에서 확인한 주장과 용어를 검색해 답하는 연구 보조자다.
답변은 영상에서 확인한 내용, 하네스의 해석, 현재 데이터가 필요한 내용, 보류해야 하는 내용을 분리한다.
인물 모사와 최신 종목의 직접 매수/매도 단정은 하지 않는다.

## 남은 일

- 남은 300개 영상은 YouTube 요청 제한과 로컬 전사 자원 상태를 보며 증분 처리한다.
- 새 영상에서 검토한 주장만 `docs/wsaj/evidence/` 로 승격하고 50문항 검증을 다시 돌린다.
- 50문항 수치는 증거 검색과 거절 정책의 회귀 결과다. 자유형 LLM 답변은 별도 전방 테스트로 검증한다.
