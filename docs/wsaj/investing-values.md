# 월가아재 투자 가치관

월가아재 자료에서 확인되는 투자 가치관은 주가 예측보다 의사결정의 기대값을 지키는 쪽에 가깝다.
핵심은 확률적 우위, 절제 우위, 손익비, 안전마진을 함께 관리하는 것이다.

## 확인된 원칙

| 원칙 | 설명 | 증거 |
| --- | --- | --- |
| 안전마진은 가격과 가치의 차이다 | 내재가치보다 주가가 낮을 때 생기는 여유분으로 본다 | `wsaj-evidence-000012` |
| 안전마진은 고정 비율이 아니다 | 가치평가 정확도, 변동성, 위험에 따라 조절한다 | `wsaj-evidence-000013` |
| 손익비는 행동과 연결된다 | 물타기와 과한 레버리지는 승률처럼 보여도 손익비를 훼손할 수 있다 | `wsaj-evidence-000024` |
| 투자 판단은 우위 관리다 | 주가 예측보다 확률적 우위, 절제 우위, 손익비를 지키는 문제로 다룬다 | `wsaj-evidence-000026` |

## 적용 조건

이 원칙은 매수 결론을 자동으로 내리는 규칙이 아니다.
하네스에서는 후보 종목이 병목 수혜, 3년 텐베거 가능성, 가치평가, 안전마진을 모두 통과하는지 확인한 뒤에만 투자 후보로 남긴다.

`wsaj-evidence-000026` 은 여러 직접 주장을 묶은 추론이다.
답변에서 이 문장을 사용할 때는 추론임을 밝히고, `wsaj-evidence-000012`, `wsaj-evidence-000013`, `wsaj-evidence-000024` 를 함께 제시한다.

## 오용 위험

안전마진을 25% 같은 고정값으로 먼저 두면 가치평가가 뒤틀린다.
물타기와 레버리지를 단순히 평단 조절이나 수익 확대 도구로만 보면 손익비가 무너질 수 있다.

월가아재 자료는 현재 매수와 매도 지시가 아니다.
현재 가격, 실적, 컨센서스가 필요한 질문에는 별도 조회가 필요하다.
