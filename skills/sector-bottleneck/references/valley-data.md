# valley 시장 데이터 수집

이 문서는 `sector-bottleneck` 실행 중 valley 시장 데이터를 수집할 때만 읽는다.

## 브라우저와 API

valley.town의 내부 API는 로그인 세션이 필요하다.
브라우저 조작은 `~/.claude/scripts/browser-driver`를 사용하고 백엔드를 직접 고르지 않는다.

| 용도 | 경로 |
| --- | --- |
| 섹터 히트맵 | `/api/financials/market-overview/sector-treemap?period=1d&contentType=USA\|KOR` |
| 종목 요약과 배수 | `/api/analysis/quote/summary?stockId=<TICKER>.<OQ\|N>&assetClass=STOCK` |
| 종목 페이지 | `/financials/quote/<TICKER>:US/summary` |

히트맵은 canvas로 그려지므로 화면 글자 대신 API 응답을 읽는다.
`contentType`은 `USA`와 `KOR`만 사용한다.
응답이 비어 있으면 현재 브라우저 주소를 확인하고 로그인 화면이면 중단한다.

거래소 접미사는 `NASD=.OQ`, `NYSE=.N`, `KRX=.KS`다.
잘못된 접미사도 성공 응답과 빈 값을 줄 수 있으므로 결측 개수를 확인한다.

`period`는 `1d`, `1w`, `1m`, `3m`, `6m`, `ytd`, `1y`, `3y`를 받는다.
같은 거래일에 여러 번 수집하면 값이 달라질 수 있으므로 기존 파일을 기본적으로 재사용한다.

## 분류와 회계연도

섹터 최상위 노드에는 이름이 없을 수 있으므로 `trbcCode`를 기준으로 묶는다.
TRBC 4자리 그룹은 서로 다른 사업을 함께 담을 수 있다.
대표 종목을 확인해 한 가지 병목으로 설명되지 않으면 종목 단계로 넘기지 않는다.

배수 응답의 `label`은 회계연도가 아니라 역년이다.
회계연도와 역년이 어긋나는 기업은 겹치는 월수로 환산한다.

```text
역년 값 = 앞 회계연도 값 × 겹치는 달/12 + 뒤 회계연도 값 × 나머지 달/12
```

비교군 값을 교체할 때는 연속한 두 해를 함께 바꾼다.
한 해만 바꾸면 두 해의 비율로 구한 성장률이 왜곡된다.

## 한국 시장

한국 시장은 실행할 때마다 컨센서스 커버리지를 확인한다.
병목 계산의 최소 데이터 품질을 통과하지 못하면 점수를 만들지 않는다.
한국 시가총액은 원화이므로 미국 달러 기준 후보 상한을 그대로 적용하지 않는다.
