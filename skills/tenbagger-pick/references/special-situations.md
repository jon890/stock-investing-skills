# 특수 상황 가치평가

일반 DCF 와 상대가치가 설명력을 잃는 사건은 먼저 분기한다.
이 문서는 일반 가치평가를 멈추고 별도 검토로 넘기는 공통 조건을 소유한다.
특정 투자 거장의 해석이 필요하면 `investing-wiki`에서 해당 expert의 근거를 별도로 찾는다.

## IPO

IPO 직후에는 사업 가치보다 물량 구조가 주가를 크게 흔든다.

먼저 확인할 것은 다음과 같다.

| 확인 | 보는 이유 |
| --- | --- |
| 공모 구조 | 총액인수인지 모집주선인지에 따라 주관사 책임이 다르다 |
| 구주매출 | 기존 주주가 현금을 회수하는 규모를 본다 |
| 신주모집 | 회사로 들어가는 성장 자금 규모를 본다 |
| 락업 | 해제 시점의 매도 물량을 본다 |
| 프리 IPO 가격 | 상장 전 시장이 준 기준값을 본다 |

상장 후 실적 기간이 짧으면 장기 마진과 성장률을 단정하지 않는다.
공모 구조와 락업 일정을 리포트의 보류 조건에 적는다.

## M&A

M&A 상황에서는 합의가와 현재가의 차이가 곧 기대수익이 아니다.
그 차이는 딜 성사확률과 시간, 규제 위험의 가격이다.

먼저 확인할 것은 다음과 같다.

| 확인 | 보는 이유 |
| --- | --- |
| 합의가와 대가 | 현금인지 주식인지에 따라 리스크가 다르다 |
| 현재가와 스프레드 | 시장이 보는 성사확률을 읽는다 |
| 마감 시한 | 기간이 길수록 연환산 수익과 리스크가 달라진다 |
| 규제 승인 | CMA, EU, FTC 같은 승인 위험을 본다 |
| 공매도와 거래량 | 포지션 청산 압력이 스프레드를 키울 수 있다 |

성사확률을 숫자로 쓰려면 근거가 있어야 한다.
근거가 없으면 스프레드 관찰까지만 남긴다.

## 은행과 보험

은행은 일반 제조업처럼 EV/Sales 나 EV/EBITDA 를 중심으로 보지 않는다.
자금이 빠져나가도 버틸 수 있는지가 먼저다.

먼저 확인할 것은 다음과 같다.

| 확인 | 보는 이유 |
| --- | --- |
| 예금 추이 | 고객 자금 유출을 본다 |
| 비보장 예금 | 뱅크런 민감도를 본다 |
| 평가손실 | 금리 상승이 자본에 준 압박을 본다 |
| Tier 1 | 핵심 자본의 질을 본다 |
| RWA | 위험가중자산 대비 자본을 본다 |
| FHLB, BTFP 같은 창구 | 유동성 버퍼를 본다 |

PBR 을 쓰더라도 자본의 질과 유동성 확인 뒤에 쓴다.

## 실적발표 직후

실적발표 직후에는 데이터 제공자 값이 늦게 갱신될 수 있다.
헤드라인 매출과 EPS 만으로 결론을 내리지 않는다.

먼저 확인할 것은 다음과 같다.

| 확인 | 보는 이유 |
| --- | --- |
| 컨센서스 대비 실적 | 시장 기대를 넘었는지 본다 |
| 다음 분기 가이던스 | 주가가 반응하는 핵심이다 |
| 사업부별 매출 | 전체 매출보다 성장 축을 본다 |
| 마진과 비용 구조 | 성장의 질을 본다 |
| 컨센서스 갱신 여부 | 낡은 추정치를 그대로 쓰지 않기 위해 확인한다 |

가이던스와 컨센서스가 10% 이상 어긋나면 회사 가이던스를 우선한다.
교체 사실은 리포트에 남긴다.

## 브랜드 소비재

브랜드 소비재는 유명세만으로 프리미엄을 정당화하지 않는다.
브랜드가 가격을 올릴 수 있는지, 그 가격이 마진과 성장률로 이어지는지를 먼저 확인한다.

먼저 확인할 것은 다음과 같다.

| 확인 | 보는 이유 |
| --- | --- |
| 마진 | 브랜드 프리미엄이 실제 이익으로 남는지 본다 |
| 성장률 | 브랜드 인지도가 매출 성장으로 이어지는지 본다 |
| 시장 침투율 | 남은 성장 공간을 본다 |
| 지역 확장 | 특정 지역 의존인지 글로벌 확장인지 본다 |
| 프리미엄 지속성 | 경쟁자가 따라오면 가격결정력이 사라지는지 본다 |

매출 집중도가 높거나 성장률이 둔화되면 프리미엄을 낮춘다.
동종업체와 비교할 때도 유명한 브랜드라는 이유만으로 높은 EV/Sales 를 받아들이지 않는다.
