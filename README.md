# 주식투자 스킬

섹터의 병목을 찾고, 그 안에서 텐베거 후보를 가치평가하며, 투자 거장의 공개 자료를 근거와 함께 탐색하는 개인 투자 하네스다.

## 진입점

| 질문 | 스킬 |
| --- | --- |
| 어느 섹터나 산업 그룹이 병목인가 | [`sector-bottleneck`](skills/sector-bottleneck/SKILL.md) |
| 병목 안에서 어떤 종목을 검토할 것인가 | [`tenbagger-pick`](skills/tenbagger-pick/SKILL.md) |
| 투자 거장의 공개 자료에서는 어떻게 보는가 | [`investing-wiki`](skills/investing-wiki/SKILL.md) |

제품 목표와 판정 기준은 [PRD](docs/prd.md), 종목 발굴 흐름은 [flow](docs/flow.md), 투자 거장 자료는 [Wiki](wiki/index.md)에서 확인한다.

이 저장소는 분석과 의사결정 기록까지만 담당한다.
매매 주문을 실행하거나 투자 거장의 인격과 말투를 복제하지 않는다.
